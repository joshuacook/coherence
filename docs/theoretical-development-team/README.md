# Theoretical Development Team Welcome

Welcome to the Theoretical Development Team! This folder contains documentation and resources
for everyone contributing to the theoretical foundations of the Coherence metric.

## Purpose
The goal of this team is to develop rigorous proofs, definitions, and connections
to information theory that will establish Coherence as a reliable metric for low-rank models.

## Getting Started
1. **Read `RESEARCH_TEAMS.md`** in the project root for an overview of all research threads.
2. Clone the repository and review the `coherence` Python package in the `coherence/` directory.
3. Familiarize yourself with existing mathematical definitions and current code.

## Initial Tasks
- Formalize the definition of Coherence using clear notation.
- Explore theoretical properties such as boundedness and monotonicity.
- Investigate relationships to mutual information and existing metrics.

## Where to Put Your Work
Use this `docs/theoretical-development-team` directory for design notes, proofs, and any
additional references specific to our team. Other teams will maintain their own folders
under `docs/` as the project grows.

## Contact
For questions or suggestions, reach out to the team lead via the repository issue tracker.
